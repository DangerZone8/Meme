05 / QUESTIONS

A few useful details.

Is this an installer?

No. The intended download is a portable Windows executable. Open the file to launch the desktop controller; there is no setup wizard.

Does the website use my webcam?

No. The reaction preview on this page is illustrative only. Webcam access happens only in the desktop app after you choose to start the camera engine.

How do I use it in a meeting?

The app can send processed frames to OBS Virtual Camera. Follow the in-app setup notes and choose OBS Virtual Camera in your meeting app's camera settings.

Does it need Python?

No separate Python installation is required for the packaged Windows app. The engine is bundled with the desktop application.
